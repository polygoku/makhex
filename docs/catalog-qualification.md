# MAKHEX supplier and build evidence gate

Every component starts as **Research** and has **no price, stock claim or checkout link**.

Before enabling a product:
1. Identify exact supplier, manufacturer/brand, product page and seller reputation.
2. Record exact SKU, board revision, flash/PSRAM, GPIO pin map, power limits, dimensions and included accessories.
3. Verify customer-facing photography permissions and provide genuine images with descriptive alt text.
4. Confirm currently selectable variant, one-unit shipping and landed cost for target markets; separately validate true checkout orderability.
5. Validate return/warranty disclosures and taxes/shipping configuration on Squarespace.
6. Create/verify the Squarespace product record and public `product/...` path.
7. Test order, stock decrement, cancellation/refund path and DSers/AliExpress order flow where applicable.
8. Check BOM compatibility with at least one bench-tested project version.
9. Record test date, evidence URLs, product and reviewer; only then enable purchase routing.

Never equate supplier search inventory with purchase availability. Never reuse LetsBorn Shopify/DSers catalog identifiers as MAKHEX verified data.
