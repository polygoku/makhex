# Sprint 09 — actual maker-build photographs and source provenance

## Where MAKHEX projects originated

The original ten MAKHEX projects were authored in Sprint 01 as internally proposed, concept-stage ESP32 blueprints. They were NOT imported from these ten outside builds. At the time, the cards displayed original illustrative artwork. MAKHEX has not assembled, flashed or independently tested the exact BOMs, and must never claim that these reference photos demonstrate otherwise.

## Independent implementation photo audit

All ten photos were obtained from the independent creators' GitHub repositories, resized to WebP while preserving actual photographs, and linked back to the original build, photo and project license. Repo license notices were copied under public/reference-builds/licenses/. The machine-readable source manifest is public/reference-builds/manifest.json.

## Display and integrity guardrails

- Each site card and project hero identifies the media as a real INDEPENDENT maker build. The detail view supplies the original repository, photo source, stage, attribution, license notice and hardware differences.
- A completed external device, an exposed working electronics assembly, a photo/CAD collage, and a MAKHEX bench-tested product are different evidence categories. None of the first three proves the MAKHEX BOM has been built or qualifies a Squarespace product.
- Repository licensing metadata does not guarantee every embedded photograph is owned by the repository author. Reconfirm photo rights before paid promotion, honor removal requests and maintain provenance. These photos must not be presented as MAKHEX-owned or endorsed images.
- Avoided a weather-dashboard photograph from mariusmym/CYD-Weather-Station because its README says personal/educational use despite GitHub labeling the repository MIT.
- Avoided the otherwise excellent finished plant monitor photographs from TikitaTolley/smart-plant-moisture-monitor; their README says photographs are CC BY-NC-SA 4.0, not suitable for commercial MAKHEX republication without permission.
- The voice cylinder uses a HYBRID cloud stack, not proven offline inference; the air-quality photo has CO2 sensing, not our SGP40 VOC device; and the desk-button reference is a finished FIFTEEN-button remote, not our one-button shortcut.

## Acceptance tests and future first-party images

The npm run qa script now confirms all ten optimized WebP files, distinct license notices, source links, stage and mismatch disclosures and generated project pages. Run Astro check/build/QA plus mobile and desktop visual acceptance.

Once MAKHEX hardware is physically assembled, replace references with new first-party photographs only after recording board revision, actual BOM, wiring, reproducible firmware commit and end-to-end bench test. Archive the independent reference credit, do not misattribute the photo.
